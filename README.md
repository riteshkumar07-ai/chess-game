# ♟️ Chess Game in Python

A simple Chess Game developed using **Python and Pygame**.

## Features

* 8×8 chess board
* White and Black pieces
* Mouse-based piece movement
* Turn-based gameplay
* Piece capturing
* Basic chess movement rules
* Simple graphical interface

## Technologies Used

* Python
* Pygame

## How to Run

Install Pygame:

```bash
pip install pygame
```

Run the game:

```bash
python chess.py
```
